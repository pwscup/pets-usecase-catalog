# プライバシー強化技術（PETs）活用事例カタログ

プライバシー強化技術（PETs）の実世界の活用事例に関する公開情報を集めて整理し、検索・閲覧できる Web カタログです。合成データ・差分プライバシー・匿名化・連合学習・秘密計算・分散データ分析の事例を扱います。

相談や依頼は、[Issue](https://github.com/pwscup/pets-usecase-catalog/issues) に書いてください。

## 事例を追加・修正したい

| やりたいこと | 読むもの |
|---|---|
| 初めて参加する | [はじめての貢献](docs/tutorial/first-contribution.md) |
| 事例を1件追加する | [事例を1件追加する](docs/howto/add-case.md) |
| AI が作った事例を確かめる | [事例をレビューする](docs/howto/review-case.md) |
| case.json の項目を知りたい | [case.json の形式](docs/reference/case-json.md) |

画面の「新規作成」や事例の「編集」からも、フォームで事例を作り、「GitHubで提出」で PR にできます。

## 開発する

```bash
npm ci
npm run dev
```

開発者向けのドキュメントは [`docs/README.md`](docs/README.md) から読めます。
